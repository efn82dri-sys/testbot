## 2️⃣ `mobile_inbox_cache.json`

**مسیر:** `data/mobile_inbox_cache.json`

**توضیح:** کش کردنِ تعدادِ درخواست‌های معلق برای صندوقِ موبایل

### نسخهٔ ساده:

```json
{
  "-1001234567890": {
    "pending_count": 3,
    "updated_at": "2024-01-15T10:30:45.123456"
  }
}
```

### نسخهٔ پیشرفته (چندین گروه):

```json
{
  "-1001234567890": {
    "pending_count": 5,
    "updated_at": "2024-01-15T10:30:45.123456",
    "last_checked": "2024-01-15T10:25:30.000000"
  },
  "-1009876543210": {
    "pending_count": 2,
    "updated_at": "2024-01-15T09:15:20.654321"
  },
  "-1005555555555": {
    "pending_count": 0,
    "updated_at": "2024-01-15T10:20:10.000000"
  }
}
```

**نوت:** 
- کلید (key) = `GROUP_CHAT_ID` بصورت string
- `pending_count` = تعدادِ درخواست‌های منتظر
- `updated_at` = آخرین بار آپدیت شدن

## 3️⃣ `vip_subscriptions.json` (ساختار موجود)

**مسیر:** `data/vip_subscriptions.json`

**توضیح:** این فایل برای تعیینِ `user_type` استفاده می‌شود

### نسخهٔ فعلی شما (احتمالاً):

```json
{
  "123456789": {
    "user_id": 123456789,
    "status": "active",
    "amount": 5000,
    "purchase_date": "2024-01-01T12:00:00",
    "expire_date": "2024-04-01T12:00:00",
    "plan_type": "vip_3_months"
  },
  "987654321": {
    "user_id": 987654321,
    "status": "active",
    "amount": 1000,
    "purchase_date": "2024-01-10T15:30:00",
    "expire_date": "2024-02-10T15:30:00",
    "plan_type": "gold_1_month"
  },
  "555555555": {
    "user_id": 555555555,
    "status": "expired",
    "amount": 5000,
    "purchase_date": "2023-12-01T00:00:00",
    "expire_date": "2023-12-31T23:59:59"
  }
}
```

**توضیح فیلدها:**
- `status`: "active" یا "expired"
- `amount`: ۱۰۰۰ تومان = gold، ۵۰۰۰ تومان = vip
- `expire_date`: تاریخ انقضای اشتراک

## 🔧 راهنمایی ایجادِ فایل‌ها

### ۱. اگر خودکار ایجاد شود:

```python
# CustomMessagesManager خودکار این کار را می‌کند
custom_messages_manager = CustomMessagesManager(CUSTOM_MESSAGES_FILE)
# → فایل با پیام‌های پیش‌فرض ایجاد می‌شود
```

### ۲. اگر دستی ایجاد کنید:

```bash
# بسازید فایلِ JSON:
mkdir -p data
echo '{}' > data/custom_messages.json
echo '{}' > data/mobile_inbox_cache.json

# سپس ربات وقتی شروع شود، فایل‌ها را پر می‌کند
```

### ۳. اگر می‌خواهید پرپولیت (Pre-populate) کنید:

```bash
# کپی کنید من فایل‌های نمونه:
cp SAMPLE_JSON_FILES/custom_messages.json data/
cp SAMPLE_JSON_FILES/mobile_inbox_cache.json data/
```

## 🆘 عیب‌یابی

### مشکل: `FileNotFoundError: custom_messages.json`

```python
# حل:
custom_messages_manager._save_defaults()
# → فایل ایجاد می‌شود
```

### مشکل: `JSONDecodeError` در خواندن فایل

```python
# چک کنید:
cat data/custom_messages.json | python -m json.tool
# اگر صحیح نیست، دوباره ایجاد کنید
```

### مشکل: فایلِ پیام‌ها نوشته نمی‌شود

```python
# اجازاتِ فایل را چک کنید:
chmod 644 data/custom_messages.json
chmod 755 data/

# یا درختِ مسیر ایجاد شود:
mkdir -p data/
```
