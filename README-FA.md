# رواق — فاز ۵ | بازطراحی تجربه کاربری و آماده‌سازی عملیاتی

## ساختار
- `main.py` — ربات و APIهای مینی‌اپ، اعتبارسنجی نشست تلگرام، ذخیره‌ی پروژه‌ها، ارسال فایل، استعلام، رویدادها، تجربه‌های اجرایی و داشبوردهای مدیریتی.
- `materials-app/index.html` — پوسته‌ی مینی‌اپ.
- `materials-app/script.js` — رابط کاربری و منطق مینی‌اپ.
- `materials-app/base.css` و `materials-app/mat.css` — طراحی و استایل‌ها.
- `materials-app/data/materials.json` — داده‌های اولیه؛ اطلاعات ساختگی قیمت یا مشخصات فنی اضافه نشده است.

## فاز ۳ — کتابخانه و پروژه‌ها
1. کتابخانه‌ی فایل‌های مرتبط با محصول؛ فایل‌ها از طریق ربات به کاربر ارسال می‌شوند.
2. پروژه‌های کاربر با شناسه‌ی تلگرام روی سرور ذخیره می‌شوند.
3. تاریخچه‌ی قیمت، نمایندگی‌ها و فرم استعلام.
4. داشبورد حامیان با آمار رویدادهای ثبت‌شده؛ این آمار معادل فروش یا کاربران یکتا نیست.

## فاز ۴ — راهنمایی، جامعه و تحلیل
1. مشاور مسئله‌محور برای ۱۰ موضوع اولیه؛ پیشنهادها فهرست اولیه برای بررسی‌اند، نه توصیه‌ی قطعی مهندسی.
2. آموزش اجرا از فیلدهای `install` محصول، با منبع و اطلاعات بازبینی در صورت ثبت.
3. تجربه‌های اجرایی کاربران با تأیید مدیر پیش از انتشار و رأی مفیدبودن.
4. شاخص بازار برای مدیران.
5. نمایش مدل عمومی HTTPS از نوع GLB/GLTF در صورت ثبت `model3d.url`.

## فاز ۵ — نظم UI/UX و پایداری
1. ناوبری اصلی از ۱۳ مقصد پراکنده به ۵ مقصد کاربرمحور کاهش یافته: کاتالوگ، پروژه‌های من، ابزارها، راهنمای اجرا و تجربه‌ها. امکانات تخصصی از طریق صفحه‌ی «ابزارها» در دسترس‌اند.
2. میزکار اختصاصی مدیر شامل شمارنده‌های محتوا، فهرست محصولات نیازمند تکمیل، ورود مستقیم به ویرایش کاتالوگ، مدیریت تجربه‌ها و گزارش‌های بازار/حامیان.
3. ذخیره‌ی محلی آخرین نسخه‌ی کاتالوگ برای نمایش در زمان قطع اتصال؛ این کش برای خواندن است و مجوز ویرایش آفلاین نمی‌دهد.
4. بخش «اخیراً دیده‌شده» با ذخیره‌ی محلی شناسه‌ی آخرین محصولات بازشده.
5. نرمال‌سازی جست‌وجو و پشتیبانی از اعداد فارسی/عربی در ورودی‌های عددی از نسخه‌های قبلی حفظ شده است.
6. محدودسازی نرخ درخواست در سطح پردازه: ذخیره‌ی پروژه، استعلام قیمت، ثبت تجربه، رأی و ثبت رویداد. برای چند worker یا چند نمونه‌ی سرور، محدودسازی مشترک مثل Redis لازم است.
7. ذخیره‌ی فایل JSON به روش موقت و جایگزینی اتمیک حفظ شده است.

## نکات استقرار مهم
- برای ماندگاری داده‌ها بعد از دیپلوی، دیسک پایدار Render را به پوشه‌ی `data/` متصل کن؛ فایل‌های JSON روی فایل‌سیستم موقت ممکن است با دیپلوی از بین بروند.
- محدودسازی نرخ فعلی در حافظه‌ی هر پردازه است و جایگزین rate limit توزیع‌شده نیست.
- قابلیت آفلاین فقط آخرین کاتالوگ کش‌شده را نشان می‌دهد؛ ارسال فایل، ذخیره‌ی پروژه روی سرور، استعلام و مدیریت محتوا به اتصال نیاز دارند.
- نمایش سه‌بعدی به لینک عمومی HTTPS معتبر و پشتیبانی مرورگر نیاز دارد.
- هیچ داده‌ی جدید ساختگی برای قیمت، مشخصات فنی، تجربه یا آموزش به محصولات اضافه نشده است.

## اعتبارسنجی انجام‌شده
- `node --check materials-app/script.js`
- `python -m py_compile main.py`
- تلاش برای آزمون تعاملی Playwright انجام شد، اما اجرای مرورگر در محیط فعلی به‌دلیل محدودیت اجرای Chromium کامل نشد؛ بنابراین تست end-to-end موفق گزارش نمی‌شود.
- API واقعی تلگرام، `initData` واقعی، دیسک Render و ارسال فایل واقعی در این محیط تست نشده‌اند.
